# Local business site template

The template behind our monthly site subscription. Each client gets a copy of this folder, and all you edit is `config.js` (name, services and prices, hours, address, phone, booking link, colors, photo, reviews). There's no build step, and it deploys anywhere static.

Includes: a hero with call and booking buttons, services with prices, reviews, hours, a map with directions, contact details, and socials.
