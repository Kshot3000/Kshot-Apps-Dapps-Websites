# Token launch site kit

A ready-to-ship landing page for a new Solana token. Every client gets their own copy; the only file to edit is `config.js` (name, ticker, contract address, colors, buy links, tokenomics, roadmap, socials), plus their `logo.svg`/`logo.png`.

No build step: deploy the folder to GitHub Pages, Netlify, or Vercel and point the client's domain at it.

Live example at `/token-launch-kit/` on the company site.
