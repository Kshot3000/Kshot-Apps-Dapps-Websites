# Changelog

## v1.0 (2026-10-31)

- First release.
- One-page token site driven by a single `config.js`: name, ticker, tagline, logo, colors.
- Contract address with a one-click "Copy CA" button.
- Buy buttons for Jupiter and DexScreener, filled in from your contract address.
- Tokenomics cards, how-to-buy steps, and a three-phase roadmap.
- Optional live DexScreener chart and Jupiter swap widget (off by default).
- Optional `/pay/` page for SOL or USDC via Solana Pay, with a QR code generated in the browser from your own wallet address.
- Setup bar that lists any placeholders you haven't filled in yet.
- No build step, no frameworks, no tracking.
